## 补齐与校验规则

1. **身份先于数值。** 国证完整目录核对总条数、分页、重复码及抓取前后交易日一致；只接收六位 `399` 代码且 `indexsource=1` 的自编指数。中证基本资料、关联列表和单张核对指数身份；单张须由官方资料列表指向同码人民币价格指数文件，且具有计算用股本说明。错码、外币或口径不明的资料不用于补值。
2. **时间和单位分别保留。** 国证目录本次交易日为 2026-11-13；滚动 PE 来自 `peDynamic`，静态 PE 来自 `peStatic`，原始市值以元计。中证单张统计日为 2026-10-30，以 `csindex-factsheet` 保存，606 条均标 `STALE`。发布日期不能取基日；采集时间按 UTC+8，重放旧原文不刷新观察日期。
3. **主序列及历史不混口径。** 已有中证官方序列优先，其次是国证，最后是经校验单张。报价 PE / PB 存独立键。不同日期或尚未证明同定义的值为 `NOT_COMPARABLE`；不能仅因百分差大就宣布某源错误。历史分位只取所选同源数据，至少 20 个有效样本且跨度 180 天；陈旧、冲突或存疑基础值不产生当前分位结论。
4. **缺失有含义。** 空白、缺失符号、非法数值和未来日期不转成 0。估值倍数须为正有限值；盈利率可为真实零或负数。PS 与 ROE 缺少对应聚合和财报期间依据时保留空值，不能以 PB / PE 比值推算。每个缺失字段都保留本次资料调查结论，未声称所有公开来源均无数据。
5. **目录计数有边界。** 明确上市交易所的境内产品归场内，未上市指数 / 联接 / 指数增强产品归场外；以产品代码去重，不推断合并 A / C 份额。129 个官方列表明确为空数组，计为该目录的 0 条；`data:null` 不等于 0。国证目录有统计日的记录为 2026-09-30，标为历史目录；中证未提供统计日时保留观察日并标 `SUSPECT`。分类不全时两个计数均不冒充完整结果。
6. **全量结构检查与事实核验分开。** 遍历 820,823 条估值、114,239 条行情，校验数值、日期、质量、重复键及误标收盘。`VALID` 仅表示本地规则通过，不等于每个历史数值已重新取得第二同口径来源。价格日期早于报告日会触发保守的陈旧提示；此次凌晨报告中的前一交易日记录不能仅凭该标记认定过期或数值错误。
7. **写入可回退、可重复。** 写前一致备份、原文 SHA-256 校验、事务落库；报价原值及同日覆盖证据留档。重复执行国证计划为新增 / 改值 / 归档均 0；参考资料最终重放的指标、发布日期及元数据变更均为 0。
